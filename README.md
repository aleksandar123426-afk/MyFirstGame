# MyFirstGame
# 🕹️ 2D Platform Game (0-Budget Indie Project)

Welcome to the repository of my 2D Platformer game! This is a passion project built entirely from scratch with **zero budget**, powered by creativity, coffee, and Unity. 

## 🚀 About the Project
This is a solo-developed 2D platformer where mechanics, level design, and programming come together to create a classic indie experience. Everything in this repository represents the core framework of the game.

## 📁 Project Structure & Code Location
To keep things lightweight and packed together for this stage of development, the codebase is structured as follows:

*   **`Assets/Scenes/`** - ⚠️ **Note:** All the game scripts, C# codes, and gameplay logic are located directly inside this folder alongside the main game scenes.
*   **`Assets/`** - Contains standard Unity graphics, inputs, and animations.
*   **`ProjectSettings/`** - Core Unity configurations.

## 🛠️ Built With
*   **Game Engine:** Unity (2D)
*   **Language:** C#
*   **Budget:** $0.00 💸

## 🎮 How to Run/Play
1. Clone or download this repository.
2. Open **Unity Hub** and click **Add** -> **Add project from disk**.
3. Select this project folder.
4. Navigate to `Assets -> Scenes`, open the main scene, and hit the **Play** button!
